# 十二函式離線重建映像

[English](readme.en.md)

`NOT-FLASH-VALIDATED-reply-integrated.bin` 是完整 76,800-byte 離線映像。
SHA-256：`0ee64183daaa140acac7dbb6c0f7c26d1fe625344ed158151731a9b2632fb667`。
內容與官方 ID2966 V4.1.60 原始解碼映像一致。

可讀 C/C++ 涵蓋十二個 IRQ／Flash／OTA 頁面回覆函式，共 650 bytes。
其餘 679 個區段仍使用原始承載資料，不能稱為完整原始碼還原。
新流程編譯 34 個承載與 9 個可讀單元，並產生 9 份 IR；61 個實際命令
包括 59 個 LLVM 操作，以及兩次明確的 ABI 指令排序。排序只重排新編譯
物件中已有的指令字，不讀取原始 BIN 作生成、填補或後備來源，也不宣稱
編譯器單獨產生最終次序。

每個編譯單元都保存完整 `-MD` 依賴，包含實際 Clang 資源標頭及其雜湊。
來源與產物檢查分別核對保留內容、全部 691 個配置區段、8,269 筆重定位、
53 個相對綁定、21 個入口及 15 個 LOAD 的完整檔案／記憶體範圍與權限。
頁面回覆保留原本 NOTYPE／size 0 公開入口及區域入口；來向 `0x9DF4`
仍是設定 RA 的 `C.JAL`。

嚴格連結仍拒絕缺少的 ROM 實作；成功連結使用的 `0x40000` 只是數值地址
見證，不包含 ROM 內容或版本證明。位元組相同也不能識別實際 TSL9 板子、
已安裝 BOOT 或使用者曾成功更新的確切檔案。

**目前未驗證可燒錄。** 這不是新增功能韌體，不是實體 OTA 測試或復原證據。
未執行或模擬 RV32，未連接 BLE／CAN／UART，未刷寫硬體。
