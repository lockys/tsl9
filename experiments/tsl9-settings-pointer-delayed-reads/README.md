# 設定指標的延後讀取

對先前三處未緊接讀取的 `GP+84` 位址產生指令，核對以下局部用途：

- `0x12C82` 將位址放進 `s7`；`0x12D78` 從 `s7` 讀取指標，再讀取指標所指 offset 4。
- `0x133C0` 將位址放進 `s4`；`0x13516` 讀取指標與 offset 4。`0x13574` 和 `0x13586` 分別新讀指標，透過間接槽請求從 `p` 及 `p+96` 各複製 16 bytes 到 stack。
- `0x18240` 以 `a3` 保存位址，`0x1824A` 隨後讀取指標；在 `0x18256` 的 unsigned 守衛通過、且寄存器與資料有效時，呼叫槽前的來源位置為 `p+16／24／32／40／48` 之一，長度 8，均在假設的 112-byte 設定區內。

這些只是指定指令的資料流：前兩項跨越其他分支與呼叫，必須假設保存暫存器與 stack 有效且未重疊指標；最後一項也須間接槽符合預期且正常返回。沒有排除其他控制流、其他寫入、異常或實機差異。

`python experiments/tsl9-settings-pointer-delayed-reads/verify.py --firmware <CANDIDATE_BIN> --r2 <R2_EXECUTABLE>` 核對固定映像、27 條指令、數值範圍與合成負例；不執行目標。
