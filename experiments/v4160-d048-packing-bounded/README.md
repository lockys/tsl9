# D048 continuation: bounded packing model

This is an offline arithmetic model of the selected reference window
`0x13928..0x1396a`, not an execution or emulation of firmware. The test pins
the 76,800-byte V4.1.60 reference by SHA-256 and checks the exact 66-byte
window (base `0x8000`); the arithmetic is manually derived from the selected
instructions, not automatically decoded from the bytes. Passing tests do not
check that the model matches the instructions or reconstructed C source.

A separate static RV32 disassembly of the pinned window gives this derivation:

| Addresses | Selected effects |
| --- | --- |
| `0x13928`, `0x1392c` | `jal ra,0xd048`; `sb a0,24(sp)` |
| `0x13930..0x1393e` | call `0x10130` with `a0=1`; mask result with `0x7ff`, shift left 8, load word |
| `0x13940..0x1394c` | form `0xfff800ff`, AND word, OR shifted result, store word |
| `0x1394e..0x1395c` | call `0x10130` with `a0=0`; mask result with `0x7ff`, shift left 19, load word |
| `0x1395e..0x13968` | form `0xc007ffff`, AND word, OR shifted result, store word |

The half-open window ends at `0x1396a`; the following call there and later
instructions are outside this model. This table is a manual derivation, not
an automated decoder test.

Let `old` be the stack word immediately before the `sb` at `0x1392c`,
after the D048 call. Assuming subsequent calls return normally, preserve the
stack pointer and do not themselves alter that word, and there are no other
intervening writes apart from the modeled stores, the word at `0x13968` is

```
(old & 0xc0000000) | (d048_return & 0xff)
| ((call_10130_with_1 & 0x7ff) << 8)
| ((call_10130_with_0 & 0x7ff) << 19)
```

Under those assumptions the entry word's upper two bits survive at that store;
its other bits are overwritten. The
first `sb` initializes only its low byte, not the whole word. These conditional
relationships do not establish callee behavior, stack aliasing, reachability,
ABI, a pure-C translation of the caller, or full-image equivalence.

The reference is a required input, not generated by this experiment. Place an
authorized copy at `firmware-downloads/legacy-options-2026-10-20/BINs/ID-2966-V4.1.60-decoded.bin`;
its required size is 76,800 bytes and SHA-256 is
`0ee64183daaa140acac7dbb6c0f7c26d1fe625344ed158151731a9b2632fb667`.
A checkout without that file cannot run the reference test.

Run `python -B experiments/v4160-d048-packing-bounded/test_packing.py` and
repeat with `python -O -B`. Tests cover each of 32 input bit positions and
4,096 deterministic composite inputs; these are finite arithmetic tests, not
proof of all firmware behavior.
