# 命令分流片段

`0x141D6..0x14230` 的 90 bytes 以原架構指令及外部 relocation 編譯成 C／C++ 物件。各有 14 筆重定位；片段在原位址連結後與原始映像逐 byte 相同。完整條件式連結另核對 `0x13BA6` 呼叫目標有可執行區段。

此片段依賴原 dispatcher frame，不能獨立呼叫。隔離測試使用 196 個來源及建置檔案，兩種候選均為 76,800 bytes 且與先前映像相同；失敗控制同樣通過。3,128-byte 載體有 344 bytes 由來源編譯、2,784 bytes 仍為原始載體。

實機 ROM、RAM、完整行為及燒錄相容性尚未驗證。
