# 新開放區段的有限狀態位址掃描

[English](readme.en.md)

執行 `python scripts/verify-payload-state-direct.py --tool-dir <LLVM_BIN> --out <NEW_OUTPUT_DIR>`。在假設 GP 為 `0x20004000` 下，檢查 `0x14056..0x14C8A` 連續解碼列中，能在單一直線片段推導的直接記憶體存取，是否碰到計數器、模式、phase 或四個序列狀態 byte。

C／C++ 原始載體各解碼 1,008 列，受檢方法均無直接命中。合成正例覆蓋 GP 相對、PC 相對、不同寬度的寫入；另測試分支清除暫存器追蹤。這些列並非全都已證明可執行，也沒有追蹤跨分支、間接指標、函式呼叫、中斷、DMA 或其他位址運算。**零命中不證明沒有其他 writer，也不建立全域索引界限。** 沒有輸出韌體運算元或驗證資料，沒有執行目標。
