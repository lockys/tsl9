# Counter 後續呼叫的局部參數

`counter-callee-prefix.py` 固定原 BIN 雜湊，核對 `0x12506–0x1253c`、`0x175e8–0x17608` 的局部指令並解碼三組 AUIPC/ADDI。依指令設定，三次對載入的指標呼叫之前，參數分別為：

| 呼叫 | a0 | a1 | a2 |
|---|---:|---:|---:|
| 0x12526 | 0x2000bfd4 | 0 | 24 |
| 0x1253a | 0x2000bfec | 0 | 36 |
| 0x17606 | 0x2000c7a0 | 0 | 268 |

第一及第三呼叫在片段內載入 `[0x40048]`；堆疊寫入若與 slot 別名，可能先改變其內容。第二次須假設前次 provider 返回且保留 s0，才可斷定其 slot 也為 `0x40048`。若這個 slot 的實作恰為只寫入 `a0` 起 `a2` bytes 的填充函數，該三區間都不包含 counter `0x200040b0`；實際 resident 身分與寫入範圍尚未知。堆疊儲存亦可能因別名寫入 counter，故不能由此推論整段呼叫無干擾。沒有執行 provider、完整函式或硬體。
