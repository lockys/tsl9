# 命令 208／240 分流

`0x144C2..0x144F8` 的 54 bytes 由 C／C++ 中的架構指令編譯，包含兩筆直接呼叫與五筆分支重定位；在原位址連結後與既有映像逐 byte 相同。208 轉往跳表；240 要求長度大於 13，經 `0x92F2` 檢查後呼叫 `0x126A0` 並回結尾。它依賴原 dispatcher frame 與未確認的訊息契約，不能獨立呼叫或視為功能完整。

207 檔隔離建置重建兩個 76,800-byte 候選，內容與先前映像一致，失敗控制通過。3,128-byte 載體中 1,056 bytes 由來源編譯，2,072 bytes 仍為原始載體；實機 ROM、RAM、完整行為及燒錄相容性未驗證。
