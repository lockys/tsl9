# 第 3 個 callback 槽與記錄物件

[English](readme.en.md)

新增七個完整 SDK 候選函式的 C/C++：**1,180 bytes／407 條指令**。這是條件式 ROM 候選研究，尚未證明原硬體採用此 ROM。

| 原位址 | Bytes | 內容／限制 |
|---|---:|---|
| `43174` | 40 | 完整鏈結記錄巡訪；未證明實際記憶體有效性 |
| `43932` | 118 | 記錄／排程輔助；保留原呼叫與分支 |
| `5E76C` | 336 | 記錄 callback；仍依賴未提供的 `60838` 本體 |
| `5E8BC` | 148 | 配置 232 bytes、設定三個 callback，條件式註冊槽 3 |
| `5ECA2` | 84 | 記錄／狀態輔助；保留三個真實既有 callee |
| `60350` | 342 | 記錄 callback；保留所有返回後可達分支 |
| `604A6` | 112 | 記錄 callback；保留延後配置的 stack frame |

`60856` 將 `5E8BC` 與 `60516` 分別寫至 RAM `2000343C`、`200034F8`。若初始化已完成、配置成功、`20003240 == 0` 且記憶體未改寫，`5E942` 呼叫 `43B28(A0=60516, A1=3)`，寫入 `200031D4`；排程器於 `20000816` 讀取、`20000818` 呼叫該槽。沒有證明實機初始化順序、即時指標或全部 callee 效果。

C11／C++17 實際物件相同，逐 byte 重編碼比對、完整 CFG／自身 frame 檢查、獨立 ELF readers 及非載入式合併均通過。合併為 **36,504 CODE＋392 DATA、12,602 條指令**，零具名 UND；這不等於零執行期依賴。51 個間接呼叫點中 **40 個**已有至少一種條件情境（30 個目標／目標集合、10 個跳過／呼叫者條件）；其餘 11 個仍未串接。

原 APP 靜態覆蓋率維持 **95.54%**。重用的 ABI 編譯斷言只檢查數值寬度；不是實體 ABI 證明。仍缺少啟動來源的 4 bytes，以及晶片、ROM、RAM、IRQ、Flash、OTA 和完整功能的實機證據。未執行目標、模型或模擬器，未產生 BIN。
