# 參考 carrier 的 `[0x40070]` 入口

兩份 WCH 參考 carrier 的 slot 都是 `0x20000236`。依既有候選啟動複製資料，若複製成功，對應入口的來源分別為 `0x404a6`、`0x404e6`；兩者已固定的前 58 bytes 相同。這個映射是條件，不是裝置 RAM 的實測。

在上述映射正確、存取成功、沒有干擾且從先前 `0xf7` 零物件路徑以 a0=12 進入時，入口先覆寫原 a1，再以 a0=20、a1=`0xf00c` 呼叫 `0x20000040`。因此在**此參考候選的這個呼叫邊界**，原始與候選版本傳來的 a1 差異不再保留；不代表後續 helper、其他暫存器或完整功能等價。a0 為零的另一條受限路徑則不呼叫 helper，也不直接覆寫 a1。

`reference_alloc_slot.py` 核對兩份 carrier 完整 SHA、slot、58-byte 入口，針對每份 slot／入口逐 byte 變造（由完整雜湊擋下），並比較 65,536 個合成 a1。這是固定 bytes 的手寫投影，未模擬 CPU 或執行 provider；沒有證明實際 resident、RAM 內容、可達性或硬體行為。缺少 carrier 時 SKIP 並以非零狀態結束。
