# 參考 `[0x40068]` 的標記分支投影

兩份固定雜湊的 WCH 參考 carrier 各自 slot 指向的 78-byte 例程包含此條件分支：假設成功讀到非零指標前兩個位元組處的 tag，tag 不等於 `0xff` 時返回 `a0=4`；tag 等於 `0xff` 才呼叫 `0x20000110`，傳遞指標並保留進入時的 `a1`。空指標走 `a0=5` 的分支。前後另有 MMIO 存取與保存還原，這個投影不建模其事件或失敗。

`reference_free_tag.py` 首先以既有檢查器固定完整 carrier 雜湊、slot、例程 bytes 及 helper 目標；每份候選以 256 個 tag 和 256 個 a1 測合成非零指標，65,280 組進標記不符的返回投影，256 組進 helper 呼叫投影，另測 256 個空指標。這些是根據固定 bytes 手寫的投影及自我一致性測試，**不是原始指令執行或獨立語義證明**。假設映射成立、讀寫成功、無中斷和干擾別名；helper 本身、a1 後續用途、裝置 resident 與硬體皆未知。缺少任一 carrier 時 SKIP 並以非零結束。
