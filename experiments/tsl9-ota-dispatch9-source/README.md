# 命令 175 比對與會合

`0x143EA..0x14446` 的 92 bytes 由 C／C++ 中的架構指令編譯，包含五筆直接呼叫與四筆分支重定位；在原位址連結後與既有映像逐 byte 相同。此片段要求 `s2==2`，將 `s0` 兩 byte 拼成 16-bit 後呼叫 `0x90B0`／`0x9334`，相等時通知 `0x9EF0` 並可能清表格 bit3、呼叫 `0x13138`／`0x820C`，最後帶命令 175 轉往 `0x1411A`。它依賴原 dispatcher frame 與未確認的表格／佇列契約，不能獨立呼叫或視為功能完整。

204 檔隔離建置重建兩個 76,800-byte 候選，內容與先前映像一致，失敗控制通過。3,128-byte 載體中 878 bytes 由來源編譯，2,250 bytes 仍為原始載體；實機 ROM、RAM、完整行為及燒錄相容性未驗證。
