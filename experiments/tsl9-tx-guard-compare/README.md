# TX 候選的一個條件式守衛比較

[English](readme.en.md)

在 V4.1.60 原廠 APP 與 TX 候選的 `0x8A76..0x8A82`，兩者先執行相同的 `bne a4,a0,0x8A96`。落入路徑接著執行相同的兩條壓縮指令；原廠在 `0x8A7E` 比較 `a4==a5`，候選比較 `a5==a0`，目標均為 `0x8A96`。

只要控制流程確由前述分支落入且沒有非同步改寫暫存器，前者成立代表 `a4==a0`，因此兩個相等比較在此局部路徑結果相同。[檢查器](check.py)只讀兩個 APP 各 12 個允許的 bytes，固定指令編碼並解碼三條分支的暫存器與目標；不執行 target。它不排除直接跳入中間的未知入口，不證明其他 TX 差異、整體 ABI、ROM 或硬體相容，也不證明此 BIN 可燒錄。
