## 正常入口與 CFG

以下地址、運算為 RV32；每一步均以之前指令可完成、未遭例外或非本地控制流打斷為條件，並不保證執行到終點。

* `18ef2–18f00`：`a4=0x40022000`；先讀取 word `[0x40022010]` 至 a5，設 a3=`0x10000`，a0 清除低 8 位，再 OR 原讀值與 `0x10000`，寫回 `[0x40022010]`。這是讀改寫，不假定原值或其他位元作用。
* `18f02–18f06`：每次重新讀 word `[0x4002200c]`，只保留 bit 0；非零 branch 回 `18f02`，零才落到 `18f08`。`18f08` 重建 a4。
* `18f0c–18f10`：每次重新讀同一地址，保留 bit 1；非零回 `18f0c`，零才落到 `18f12`。該零值亦留在 a5，因而正常進入迴圈時 a5=0；`18f12` 重建 a4，`18f16` 設 a2=256。
* `18f1a–18f32`：先算 `a1+a5`、從該地址 `lw a6`，再算已遮罩的 `a0+a5`、`sw a6`；然後 `18f2a` 重讀 `[0x4002200c]`，mask 2；非零由 `18f2e` 回 `18f2a`，零才執行 `a5 += 4`；`18f32` 的 `bne a5,a2` 非相等回 `18f1a`，相等落到 `18f36`。按 32 位暫存器計算、且每次存取和 polling 都完成、控制流及暫存器未被外部改變時，offset 是 0,4,...,252 共 64 次；每次先讀來源再寫目的，接著才 polling。並非一次 256-byte 原子複製或先讀完所有來源。
* `18f36–18f3e`：讀 `[0x40022010]`、OR `0x200000`、寫回。`18f40` 再設基址；`18f44–18f48` 每次讀 `[0x4002200c]` 並測 bit 0，非零回 `18f44`，零才繼續。
* `18f4a–18f54`：讀 `[0x40022010]`，與 `0xfffeffff` AND 後寫回，最後 `ret`（由 ra 間接跳轉）。若正常抵達 ret，a0 仍是入口 a0 清低 8 位後的數值；這不賦予回傳值成功意義。

上述四個 polling 均無程式內 timeout；被測位元若不出現零，對應迴圈可無限持續。不存在直接 JAL 呼叫；ret 的實際目的由 ra 決定。完整正常返回還依賴各次取指、讀寫、對齊、權限和環境均允許，所有 polling 最終通過，且 ra 與控制流未被改變。這些是條件，不是保證。

## 物件、別名及限制

`a1` 只是入口寄存器值，`a0 & 0xffffff00` 只是目的位址計算；無證據證明它們是有效物件、長度、型別、記憶體種類或互不重疊。地址相加按 RV32 截斷；來源與目的可重疊，早期 store 可改變後續 load，亦可能別名上述控制位址、程式、其他執行者或其他物件。每次 load/polling 必須依其實際時點考慮，不能把它們合併、快取或假定所有讀值穩定。對 `0x4002200c/10` 僅記錄固定地址及指令層級讀寫（常被稱作 MMIO）；未憑地址推定周邊、位元功能、寫入副作用、硬體完成、儲存成功、可重入性或一致性。中斷、例外、其他 agent、匯流排或裝置副作用均未建模，亦不能排除；這些可改變記憶體或控制流。無法由靜態位元組證明實際呼叫、終止或 target 的硬體行為。
