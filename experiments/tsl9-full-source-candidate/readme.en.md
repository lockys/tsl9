# V4.1.60 candidate image source build

[繁體中文](README.md)

Run `python scripts/build-v4160-source-candidate.py --tool-dir <LLVM_BIN> --out <NEW_OUTPUT_DIR>` to compile C and C++ from `src/` and the project build tools and emit a 76,800-byte candidate for each mode. The builder checks the resulting SHA-256 against the existing TX-integrated candidate without reading that BIN during the build.

The full build first checks conditional linking: two symbols have section backing and three data symbols use conditional aliases; the strict link still lacks `0x40000`. A diagnostic link uses a numeric address witness and is compared byte for byte with the independently assembled BIN. This does not prove the ROM, RAM, or index assumptions.

The 3,128 bytes in `src/native/tx_candidate/full-image-payload.json` retain the candidate's original bytes for comparison. During the build, the [66-byte entry and forwarding fragment](../../src/native/receive/ota_entry_14056.inc), [14-byte epilogue](../../src/native/receive/ota_epilogue_14098.inc), [54-byte continuation](../../src/native/receive/ota_more_140a6.inc), [70-byte command path](../../src/native/receive/ota_ae_140dc.inc) [50-byte command path](../../src/native/receive/ota_ad_1417a.inc), [90-byte dispatcher](../../src/native/receive/ota_dispatch_141d6.inc), [88-byte continuation](../../src/native/receive/ota_dispatch_14230.inc), [56-byte branch](../../src/native/receive/ota_dispatch_14288.inc), and [60-byte check](../../src/native/receive/ota_dispatch_142c0.inc) are compiled from C/C++ architectural instructions and replace the corresponding carrier bytes; the remaining 2,580 bytes still come from the opaque carrier. These fragments depend on the original control flow and stack frame and cannot be called independently. Other sources may also carry original instructions or data. Reproducing the bytes does not prove complete source recovery, closure of strict-link dependencies, device boot, or functional equivalence. Numeric address witnesses remain part of the diagnostic layout.

**The candidate has not been validated as safe to flash.** Original device ROM/ABI, RAM, IRQ, OTA and functional behavior need independent evidence. This build does not operate hardware.
