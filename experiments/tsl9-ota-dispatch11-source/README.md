# 命令 193／192 分流

`0x1447A..0x144C2` 的 72 bytes 由 C／C++ 中的架構指令編譯，包含四筆直接呼叫與八筆分支重定位；在原位址連結後與既有映像逐 byte 相同。193 轉遠端處理；大於 193 落到後續 208／240 路徑；192 依 `s2` 與 `s0[0]` 分支，落在 2 時呼叫 `0x13BA6` 與三次 `0x12AA0` 後回結尾。它依賴原 dispatcher frame 與未確認的回呼契約，不能獨立呼叫或視為功能完整。

206 檔隔離建置重建兩個 76,800-byte 候選，內容與先前映像一致，失敗控制通過。3,128-byte 載體中 1,002 bytes 由來源編譯，2,126 bytes 仍為原始載體；實機 ROM、RAM、完整行為及燒錄相容性未驗證。
