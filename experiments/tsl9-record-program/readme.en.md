# Native324B record-path verification

[繁體中文](README.md)

Selected source:`src/record_program.v3.c`; curated copy:`src/native/receive/record_program.c`. Earlier failed trials and raw receipts remain immutable. Nineteen private regions occupy their original addresses through nominal.ld and match the complete324B range. joined.ld emits only a2250B diagnostic ET_REL, not executable firmware.

The commands in [the Traditional Chinese guide](README.md) require retained local1926B parent objects, the previous strict13-source proof, current curation receipt/objects, the original BIN and the pinned installed LLVM tools. Private build objects are not published through Git. Missing inputs fail without downloading replacements.

Choose a new output directory for build.py, then run verify-v2.py with`--write` for c/cpp. Existing formal artifacts are under`build/formal-v1/{c,cpp}`; omitting`--write` reproduces saved verification-v2.json bytes read-only. The v1 receipt is historical; v2 fixes nominal FUNC section ownership/extents. Original/curated STT_FILE names differ, so whole-ELF identities must not be conflated with code equality.

Scripts only compile/link/read data. They do not execute HOST behavior models, ISA instructions or hardware. These physical frame/register/control ports require original placement and are not ordinary C APIs.
