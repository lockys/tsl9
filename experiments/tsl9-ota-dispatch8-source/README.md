# 命令 169 比對與後續序號

`0x143A4..0x143EA` 的 70 bytes 由 C／C++ 中的架構指令編譯，包含七筆分支重定位；在原位址連結後與既有映像逐 byte 相同。此片段以 GP+84 表格與 `s0` 記錄做 byte 比對，相符則轉往 `0x14A96`，否則帶命令 169 轉往 `0x1411A`；接著篩選 187／176／175。它依賴原 dispatcher frame 與未確認的表格／命令契約，不能獨立呼叫或視為功能完整。

203 檔隔離建置重建兩個 76,800-byte 候選，內容與先前映像一致，失敗控制通過。3,128-byte 載體中 786 bytes 由來源編譯，2,342 bytes 仍為原始載體；實機 ROM、RAM、完整行為及燒錄相容性未驗證。
