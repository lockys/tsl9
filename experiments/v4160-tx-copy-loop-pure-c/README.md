# V4.1.60 TX copy loop：隔離 ISO C 候選

這是可讀的有限共同 RAM 模型，**不是韌體替換、裝置程式或 C 正確性證明**。入口是原始 `0x8b0a` 執行之前，出口是分支未成立、即將執行 `0x8b14` 之前；不包含前置封包建構、完成路徑、呼叫或 return。`candidate.c` 是獨立 ISO C，沒有 callback、inline asm、restrict 或 memcpy。它並未編譯或執行。

## 逐指令核對

以原始 `firmware-downloads/legacy-options-2026-10-20/BINs/ID-2966-V4.1.60-decoded.bin` 的 `[0x8b0a,0x8b6c)` 靜態窗口為準，實際 r2（RV32，映射基址 `0x8000`）與 `src/native/receive/transport_frame.c`、`experiments/tsl9-tx-guard-compare/check-loop.py` 對照：

| 位址 | bytes | 指令與作用 |
|---|---|---|
| 8b0a | 13950501 | slli a0,a1,16 |
| 8b0e | 4181 | srli a0,a0,16；a0 為 a1 低 16 位 |
| 8b10 | 63618504 | bltu a0,s0,8b52；否則出口 8b14 |
| 8b52 | 3385b400 | add a0,s1,a1 |
| 8b56 | 03450500 | lbu a0,0(a0) |
| 8b5a | 3388b700 | add a6,a5,a1 |
| 8b5e | 8505 | addi a1,a1,1 |
| 8b60 | 2a97 | add a4,a4,a0，RV32 低 32 位 |
| 8b62 | a302a800 | sb a0,5(a6) |
| 8b66 | 1377f70f | andi a4,a4,255 |
| 8b6a | 45b7 | j 8b0a |

函式接收進入時的 `s0,s1,a5,a1,a4,a6`，返回出口的 `a0,a1,a4,a6`：`a0` 每次測試重設成低 16 位；`a1` 是完整 32 位；`a4` 若未進入本體則原樣，否則每次儲存後取低 8 位；`a6` 若未進入本體則原樣，否則為最後一次 `a5+a1`（使用遞增前的 a1）。`s0,s1,a5` 不變，其他暫存器不在此介面內且該區段不改寫。C 無條件碼輸出；加總先以 `uintmax_t` 無號運算再轉回 `uint32_t`，得到模 2^32 結果，再取低 8 位，進位不另存；此寫法避免在 `uint32_t` 會提升為有號 `int` 的實作中發生有號溢位。先 volatile load，後 volatile store，兩者共用同一物件，因此重疊可影響後續 load。

## 契約及限制

`ram` 指向一個有限的 `volatile uint8_t` 陣列，所有執行到的來源 `s1+a1` 與目的 `a5+a1+5` 都必須是該同一陣列內有效索引；此處各地址加法及 `a1` 遞增都須在數學上不超過 `UINT32_MAX`，且陣列必須存在於實作可表示的物件大小內。參數以索引而非實體位址表達；這是受限契約，**不是**聲稱原機器指令截斷索引或限制地址範圍。沒有邊界檢查、同步、非同步介入、故障或任意 MMIO 語意。必須呼叫者保證條件，不符合即超出模型。

此安全 C 契約另要求 `s0 <= 65535`。原機器若 `s0 > 65535`，每次比較用的值至多 65535，正常無干擾下無出口；低 16 位會回捲，完整 32 位 a1 與地址最終也會回捲。這些 nonreturn／32 位回捲執行不納入有限有效 RAM 的安全 C 空間；不能把早期 `1039` guard 當作 opaque 呼叫後 s0 的保證。`s0 <= 65535` 時低 16 位從入口起始值遞增至 s0 即停止，或一開始已不小於 s0 而直接退出。

## 離線檢查

`python experiments/v4160-tx-copy-loop-pure-c/test_offline.py` 及 `python -O .../test_offline.py` 只讀原 BIN 指定窗口與候選源碼；固定整個窗口、個別指令 bytes/運算元註記以及 candidate.c SHA-256，並對窗口逐 byte 和源碼變異確認無法繞過 pin。窗口的運算元註記是獨立 r2 靜態抄錄，不是由測試程式反組譯驗證；整個窗口 pin 成功後逐條 bytes 比對並非獨立語義負例。BIN 窗口外內容及測試自身常數與程式未由本測試固定，source 負例只測尾加空白。Python 模型只展示獨立事件例子：重疊向前傳播、32 位累加進位、完整索引跨 65535 邊界及零次迭代；**不是對 C 的測試或等價證明**。不執行 target、模擬器或網路設備。
