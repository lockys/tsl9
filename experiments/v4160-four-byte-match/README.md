# 四位元組比對的受限 C 語意投影

原始 BIN `[0x14122,0x1417a)` 的路徑在 `a3 == 4` 時，逐一將 `s0[i]` 與設定資料指標偏移 `12+i` 的位元組比較；不相等時再與堆疊常數 `0x62426141` 在小端序下的對應位元組（`41 61 42 62`）比較。四個位置均可分別選擇任一來源，不要求整段一致來自同一來源；首個兩者皆不符的位元組會走失敗分支。

`model.c` 僅投影四個讀取成功、資料穩定的位元組判斷。它不處理長度檢查、指標及記憶體有效性、實際讀取順序與副作用，也不執行後續分支或兩個函式呼叫。`verify.py` 固定 BIN 雜湊及 88-byte 指令視窗，再以 C11/C++17 執行各 16,401 個合成測試。`machine.py` 另以有限 RV32I/C 解碼器執行原始 bytes 至成功、失敗或長度不符出口；`differential.py` 在 C 與 C++ 下各比較 17,400 組，另檢查六個非 4 長度。另外比對合成記憶體的讀取次序、設定值相符時跳過備用值、首個不符時停止，以及長度不符時不讀取；五個指令變造造成不同行為或遭解碼器拒絕。解碼器與模型皆為自製，可能有共同錯誤；模擬記憶體與設定值是假設，成功路徑在第一個外部呼叫前停止。沒有實機或原位址 byte-exact C 宣稱。

```text
python -I -B experiments/v4160-four-byte-match/verify.py --vcvars <vcvars64.bat>
```
