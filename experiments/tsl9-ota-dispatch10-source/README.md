# 命令 185／186 分流

`0x14446..0x1447A` 的 52 bytes 由 C／C++ 中的架構指令編譯，包含兩筆直接呼叫與六筆分支重定位；在原位址連結後與既有映像逐 byte 相同。185 轉往遠端處理；186 要求 `s2==1` 且 `s0[0]` 為 2，然後呼叫 `0x1264E`／`0x136D0` 並回到結尾。它依賴原 dispatcher frame 與未確認的訊息契約，不能獨立呼叫或視為功能完整。

205 檔隔離建置重建兩個 76,800-byte 候選，內容與先前映像一致，失敗控制通過。3,128-byte 載體中 930 bytes 由來源編譯，2,198 bytes 仍為原始載體；實機 ROM、RAM、完整行為及燒錄相容性未驗證。
