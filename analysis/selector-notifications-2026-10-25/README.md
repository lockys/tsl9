# 通知分派與五張跳轉表

[English](readme.en.md) · [來源](../../src/native/receive/selector_notifications.c) · [證據](provider-contracts.json) · [統計](summary.json)

重建官方 BIN 的 E220..EBAC：2,444B／789 條指令。五張唯讀相對位址表共 756B、189 項；原生 C11／C++17 編譯後，每個表項與範圍檢查都逐位元組核對，表項均落於實際指令。保留原始分支、呼叫順序與明確的私有暫存器組合語言介面。這不是完整原始碼還原。

完整來源 220 組比較／440 個物件通過；整合後 48,858B 原址吻合。補齊 E220 並揭露 16 個新下游函式，仍缺 137 個提供者。FE08 同時有直接呼叫與回呼位址參照。

已確認：靜態指令、資料、跳轉位置與 C/C++ 物件一致。推論：通知代碼驅動多層 selector 分派。未確認：按鍵／座椅等功能歸屬、私有 ABI、實際記憶體／中斷／OTA。沒有執行目標、硬體或新 BIN；不得將診斷 ELF 當成可刷韌體。
