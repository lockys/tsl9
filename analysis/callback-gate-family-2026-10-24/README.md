# 回呼條件與原始暫存器設定

[English](readme.en.md) · [C/C++](../../src/native/receive/callback_gate_family.c) · [原始證據](evidence.json) · [驗證摘要](summary.json)

新增8個完整原始函式，370B／121指令，C11／C++17編譯與原址碼吻合。已接上9AF0、B5B4、D314、D3E8及主初始化9B4E；真正未實作提供者由76降至71，沒有新增依賴。

| 原始範圍（結尾不含） | 已確認靜態行為 |
| --- | --- |
| 9A24–9A42 | 保留32B frame；在SP+4建立半字／word設定描述，再呼叫18F88。 |
| 9AD2–9AE4 | 設GP+168 byte為1，再將32位值2寫至0x40010814。 |
| 9AF0–9B02 | 重新讀GP+168 byte，為0時將32位值2寫至0x40010810。 |
| 9B4E–9B8E | 清除GP+168；依word(GP+84)所指設定的byte3 bit4，選擇送出9AD2回呼與參數5000。以A0=0x40010800、A1=2、A2=16呼叫9A24，最後尾呼叫9AF0。 |
| B5B4–B5C6 | 讀取0x2000BEEF byte，回傳大於1的布林值。 |
| D314–D322 | 讀取0x2000BF5C半字，回傳是否非0。 |
| D3E8–D3F6 | 讀取0x2000BF5F byte，回傳是否非0。 |
| 18F88–1904A | 完整保留低／高8位遮罩迴圈、word偏移0/4/16/20及模式40/72分支；包含第一個RET後的19038–1904A分支。 |

既有D322已讀同一半字並輸出0或2，本輪沿用、不重複定義。不同getter各自重新讀取，沒有證明一致快照。9AE4起的相鄰獨立函式未混入9AD2。設定迴圈呈現GPIO類型的結構屬推論；實際晶片、腳位、外接裝置、時間單位、ROM與同步契約仍未證。

主元件16104B code＋674B data，共16778B經原生連結器配置後，逐byte等於官方ID2966 BIN。來源共107個C/H檔、80個原生code單元，162項比較／324個物件通過；保留所有舊106檔與949筆產物記錄。靜態流程938直接轉移、270暫存器間接轉移、320潛在返回位置；不是完整CFG或執行證據。診斷ELF入口0、PT_LOAD=0，尚不能燒錄。

候選新增工具：離線比較各版本的設定bit、GP狀態與回呼參數，保留原始值與未知單位；目前僅提案。下一步追查8E88／9958／9F12／9E84與原機契約。未執行韌體、HOST模型或ISA模擬，未連硬體／網路。歷史隱私問題仍待清理，未commit／push。
