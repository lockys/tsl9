# 重設記憶體區段：原始契約

原始 ID 2966 V4.1.60 映像為 76800 位元組、基址 0x8000，SHA-256 是 `0ee64183daaa140acac7dbb6c0f7c26d1fe625344ed158151731a9b2632fb667`。選定 `0x186BA..0x186F8` 共 **62 位元組、17 條指令**，含十四條 4 位元組及三條壓縮指令；區段 SHA-256 為 `aea8841ab98f92a2372b602ee5c7667e626faac48814dd49d86893392f7273ac`。

既有 ID2966 reset-contract 對照表列出完整 138 位元組重設本體 `0x186AA..0x18734` 及 128 位元組初始化資料 `0x1AB60..0x1ABE0`；本輪沿用並檢查其雜湊。較早的第六十五輪證據使用另一個映像（`32639d7d...`，重設位址 0x183FE），不能把其位址、136 位元組初始化資料或邊界套用於本版。既有時脈來源封存另涵蓋重設前 52 位元組 `0x186AA..0x186DE`；本輪小型原始位元解碼只補足完整記憶體區段，不改寫舊證據。

## 入口與三次 GP 讀取

原始前綴 0x186AA/0x186AE 的 PC 相對位址對形成 GP=0x20004000；0x186B2/0x186B6 形成 SP=0x20010000。這是靜態位址計算，不是實際暫存器或 RAM 有效性的觀察。本區段不寫 GP、SP、RA，沒有呼叫、RET 或形成 RA；正常完成是落入區段外的 0x186F8，不能當作原有 C 函式返回。

三條指令各自讀取當時 GP：

| PC | 指定結果 |
|---|---|
| 0x186C2 | A1 := GP |
| 0x186C6 | A2 := low32(GP+128) |
| 0x186DE | A0 := low32(GP+128) |

原始本體不改 GP，無外部影響時可保持相同；但靜態程式與 C 介面都不能證明沒有外部暫存器或陷阱效果。若重建聲稱涵蓋任意即時 GP 變動，就必須保留三個獨立形成點；單次呼叫固定 GP 的 C 介面則需明列假設。

## 向前複製字組

0x186BA/0x186BE 依其原始 PC 相對位址對形成 A0=0x1AB60；0x186C2 取目的地 A1，0x186C6 另取排除式邊界 A2。0x186CA 以**無號** A1>=A2 時略過複製，跳往 0x186DE；否則每次依序：

1. 0x186CE 從 A0 READ32 至 T0。
2. 0x186D2 將當時 T0 WRITE32 至當時 A1。
3. 0x186D6 將 A0 加四，保留低 32 位。
4. 0x186D8 將 A1 加四，保留低 32 位。
5. 0x186DA 以無號 A1<A2 決定重複。

不能先讀完全部資料再寫入。原始是向前逐字複製，來源／目的地重疊可能改變之後讀取，不能用一般重疊安全的 `memmove` 語意取代，C `memcpy` 也不能證明重疊行為。本區段未檢查位址有效、對齊或不重疊；讀寫錯誤、非同步修改與實際記憶體效果仍未知。

令複製起點 d、邊界 e 均為 32 位元無號數。d>=e 時略過，保留輸入 T0。d<e 且 `e <= 0xFFFFFFFC+(d&3)` 時，正常算術經 `ceil((e-d)/4)` 次到達第一個 >=e 的游標，目的地不會先回繞。若 e 超過 d 除四餘數類別中最大的 32 位元數，反覆加四會回繞且永遠無法達到 >=e；原始沒有次數上限。大量複製還可能使來源位址回繞。合成測試預算或安全 C 拒絕是另外的邊界，不能宣稱原始已正常完成。

## 清零與延續時的輸出

0x186DE 不論複製有無執行，均以**第三次** GP 讀取覆寫 A0。0x186E2/0x186E6 的原始 PC 相對位址對形成 A1=0x2000C958。0x186EA 在無號 A0>=A1 時跳到 0x186F8；否則 0x186EE 對 A0 WRITE32 零、0x186F2 將 A0 加四並保留低 32 位、0x186F4 在無號 A0<A1 時重複。清零沒有 READ32，也不改 T0。

令 z=low32(第三次 GP+128)、E=0x2000C958。z>=E 時略過清零，最終 A0=z。z<E 且寫入均成功、沒有外部暫存器修改時，經 `ceil((E-z)/4)` 次後，最終 A0 為 z 的除四餘數類別中第一個 >=E 的值。E 低於 0xFFFFFFFC，因此在抵達 E..E+3 前不會回繞。未對齊的 z 可能造成未對齊寫入或越過排除式邊界最多三位元組，未證明實體硬體可接受或正常完成。

區段正常延續到 0x186F8 時：

- A1=0x2000C958，含複製／清零略過情形。
- A2=low32(第二次 GP+128)，自 0x186C6 後不再改寫。
- A0 是上述清零最終游標或略過時的 z，先前來源游標已被覆寫。
- 複製略過時 T0 保留輸入，否則為最後成功讀取的複製字組；清零不把它清掉。
- 其他整數暫存器均未被本區段寫入，包含 A3..A7、GP、SP、RA。明確目的地只有 x5/T0、x10/A0、x11/A1、x12/A2。

三次 GP 均為 0x20004000 時，原始複製 32 組 READ32／WRITE32，再對 `0x20004080..0x2000C958` 作 8758 次 WRITE32 清零。最終 A0=A1=0x2000C958、A2=0x20004080。確切檔案內最後初始化字組位於 0x1ABDC，位元組 `a1 03 00 00`，值 929；只有原始映射資料確實提供相同讀取且正常完成時才可推得 T0=929，這不是實體觀察。接著 0x186F8 會設 T0=31，但該指令在本區段之外，不可提前併入輸出。
