# 輸入與狀態解碼

[English](readme.en.md) · [來源](../../src/native/receive/input_state_decoders.c) · [合約](provider-contracts.json) · [統計](summary.json)

重建16個完整函式，共1,822B／594條指令：長frame輸入處理、兩種格式wrapper、selector群組、條件紀錄改寫、回呼介面、四狀態判斷與20～23模式寫入。A2EA是4B wrapper，尾跳到既有A204；未複製其本體。

D76C依序讀取四個靜態byte並判斷是否全部等於2；四個鄰近入口將20/21/22/23寫入同一個靜態byte。C472將record[8]的三個2-bit群組交給ECA8，搭配selector120/121、128/129、136/137及GP+216/217/218；功能名稱與單位未確認。

230組比較／460個物件通過；53,520B原址吻合，覆蓋率69.69%。補齊8個入口，新增3個函式與1個資料缺口，仍缺105個提供者。七處回呼均接到實際程式碼；1AB48只保留位址參照，不提供內容或單獨payload雜湊，也不計入重建資料。

已確認：原始指令、bit群組、靜態位址、分支與回呼角色。推論：這組函式支援輸入條件及狀態分派。未確認：實車功能、欄位單位／邊界、1AB48表格範圍、實體ROM/RAM、私有ABI、中斷與OTA。沒有目標／硬體執行或新BIN；百分比不是功能完成率或可刷入程度。
