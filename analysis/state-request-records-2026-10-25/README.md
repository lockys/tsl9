# 狀態請求與紀錄改寫

[English](readme.en.md) · [來源](../../src/native/receive/state_request_records.c) · [合約](provider-contracts.json) · [統計](summary.json)

重建11個完整函式，共740B／256條指令：FBA2紀錄改寫、延遲消費回呼、成對回呼切換、狀態位元解碼、私有continuation與ROM表項wrapper。82A8存取wrapper原本已存在，本輪不重複計入；其ROM內部身分仍未證明。

FBA2保留GP+288/289/290等狀態分支、bytes3/4/5/6的遮罩改寫，以及byte9高nibble在三個位置的遞增。部分分支會遞增多次，不合併；保留ED00(A1=7)、record[2]+2的動態檢查byte位置與12A08尾跳。邊界、欄位用途及檢查算法名稱未確認。

228組比較／456個物件通過；51,698B原址吻合，覆蓋率67.32%。補齊7個入口、揭露D76C，仍缺109個提供者。五處回呼均接到實際程式碼，七張既有跳轉表重新核對。

已確認：原始指令、分支順序、靜態位址、欄位遮罩與回呼參照。推論：這組函式支援狀態請求後的紀錄轉換。未確認：車輛功能歸屬、緩衝區邊界、時間單位、ROM/RAM、私有ABI、中斷及OTA。沒有目標／硬體執行或新BIN；百分比不是功能完成率或可刷入程度。
