# 執行服務與回呼連結

[English](readme.en.md) · [C/C++ 來源](../../src/native/receive/runtime_service_links.c) · [指令／資料合約](provider-contracts.json) · [統計](summary.json)

重建18個完整函式，共706B／236條指令，另有原碼可索引的8B唯讀窗口。涵蓋狀態計數、byte／halfword清理、排程／取消包裝、長回呼與查找比較。

E0BA保留36個呼叫與條件順序；其狀態清理用途是推論，不能當成實體恢復原廠設定。E1A6保留32位元時間差與1999門檻，時間單位未知。17BC4本身只包裝回呼與既有服務，沒有直接MMIO。

F9EC先將索引遮罩為0..7，索引0直接返回；其餘索引讀取1AB58..1AB60窗口並做unsigned比較。8B內容與原廠BIN相符；原始表格宣告範圍、物理量與單位未確認，不能擴大解讀為整張表已還原。四處回呼均接到實際程式或本輪新回呼，資料參照則接到真正唯讀物件。

236組比較／472個物件通過，55,592B原址相符，覆蓋率72.39%。補齊13個入口，沒有新增直接／回呼／資料缺口，仍缺85個提供者；其他不明資料內容維持未提供。新函式的直接依賴均有實作，整體傳遞呼叫圖仍未完成。

實車功能、私有ABI、實體ROM/RAM、中斷與OTA相容性仍未確認。無目標／硬體執行或新BIN；百分比不是功能完成率或可刷入比例。候選新功能是唯讀回呼清理與門檻比較追蹤，尚未整合App或車輛功能。
