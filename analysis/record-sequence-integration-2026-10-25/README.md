## 資料與標籤

三個來源 `0x1A430`／`0x1A454`／`0x1A478` 的標籤位於同一個178-byte readonly owner內，偏移0／36／72。標籤本身不新增bytes；它們是有實際section backing的OBJECT符號，沒有用ABS位址或假函式替代。原有 `0x1AB60` 啟動資料標籤也完整保留。

資料池範圍來自[選定來源常數與局部上限的保守聯集](../record-sequence-pool-2026-10-25/README.md)，不是原始宣告長度或任意RAM值的全域界限。它保留這批原始bytes與來源間的位址關係，沒有宣稱非同步執行或ROM副作用已被完整涵蓋。

## 非載入中繼資料

本輪原生元件保留了一個位於非ALLOC `.comment` 的本機編譯器標記 `$d.1`。它沒有重定位參照，也不屬於韌體記憶體。拆分器只排除這個已確認標記，並額外核對其餘本機／全域符號角色；所有實際程式、資料、內部標籤與重定位驗證仍保留。
