# 原始周邊初始化與描述子

[English](readme.en.md) · [C/C++](../../src/native/can/peripheral_initializer.c) · [原始指令](evidence.json) · [驗證摘要](summary.json)

重建完整18AB0–18BA2，共242B／99指令、27個私有區塊與17個控制重定位，保留第一個RET後六條清除分支。沒有外部呼叫；接上主初始化的真實入口，未解析提供者76→75。相鄰filter18BA2與IRQ helper18CA4既有實作保持不變。

程式先清除control bit1、設定bit0，以65536初值輪詢status bit0，輪詢後重新讀取狀態；沒有進入確認時返回0。六個設定旗標以完整32-bit word等於1決定設定，其他值走清除分支，沒有改成低byte或一般非零判斷。

| 32B描述子欄位 | 原始運算 |
| --- | --- |
| halfword+0 | 減1後參與OR，不新增遮罩或有效範圍檢查 |
| byte+2／3／4／5 | 分別左移30／24／16／20位 |
| word+8／12／16／20／24／28 | 等於1時設定control bit7／6／5／4／3／2，否則清除 |
| byte+6／7 | 本函式沒有讀取，型別中保留 |

組合結果寫入base+28，之後清除control bit0，再以65536初值輪詢status bit0，最後返回(~fresh_status)&1。兩個計數器不是毫秒；返回值的實體成功意義、時鐘、CAN位元率與MCU型號仍未由本輪證實。

C/C++內新增描述子型別，七個編譯期斷言核對32B大小與原始欄位offset。這證明選定RV32工具鏈的型別版面，不等於實體硬體或完整私有ABI驗證。未執行型別模型或周邊程式。

目前115個C/H檔、88個code單元，含獨立指標資料共178項比較／356個物件，舊114個來源與1045筆產物記錄不變。主元件20988B code＋714B data，共21702B在原生原址配置後逐byte等於官方ID2966 BIN；仍缺75個真實提供者。

流程覆蓋7287指令、1200直接轉移（1125已重建／75僅參照）、6728個一般下一位置無缺口、448個可能呼叫返回位置；374個暫存器間接轉移、10個MRET與1個EBREAK仍非完整CFG或實機證明。診斷ELF入口0、PT_LOAD=0，不可燒錄。

component-v1沿用複數收據欄位名稱，已修正並實際重新產生component-v2；兩者機器碼相同，未改來源或放寬檢查，舊產物保留。下一步六個設定fallback先做隱私檢查。可新增的離線描述子／時鐘契約檢視工具目前僅提案，不猜實體位元率。未執行目標／HOST模型／ISA模擬，未操作硬體或網路；歷史隱私問題未清理，未commit／push。
