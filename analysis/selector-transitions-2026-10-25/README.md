# Selector 狀態轉換

[English](readme.en.md) · [C/C++ 來源](../../src/native/receive/selector_transitions.c) · [指令與合約](provider-contracts.json) · [驗證統計](summary.json)

重建三個完整函式 AB08、AB7C、ECA8，共246B／94條指令、31個私有區域。相鄰 getter 已存在，沒有重複計算。

AB08 保留狀態相同比對、單次旗標及動作／排程呼叫順序；歸零路徑傳入數值1000，其單位未確認。AB7C 比較新值與0x2000BEE8舊 byte，在條件允許時依增減選擇動作150／151，然後儲存低8位並回傳變更旗標。ECA8 只接受兩個指定值；依 guard 結果決定寫狀態或派送動作，保留先寫入再呼叫的順序。guard 非零且狀態改變時，回傳保存的原 guard 值，不擅自改成布林值。

232組比較／464個物件通過，53,766B原始位址相符，覆蓋率70.01%。補齊三個既有依賴，沒有新增缺口；仍缺102個提供者。既有1AB48資料表與其他不明資料內容維持未提供。

已確認的是原始位元組、比較／寫入寬度及呼叫順序；推論為 selector 狀態處理。實車功能名稱、數值單位／範圍、私有ABI、實體ROM/RAM、中斷與OTA相容性仍未確認。沒有目標／硬體執行或新BIN；百分比不是功能完成率或可刷入比例。候選新功能是離線狀態轉換追蹤，尚未實作成車輛控制或App功能。
