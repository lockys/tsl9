# 回呼缺口與輸入組裝：離線重建

五個完整函式已重建為 C，並分別以 C11／C++17 編譯；444 bytes、162 條指令、29 個直接轉移與兩組回呼位址均通過原始指令比較。組語 port 保留原機暫存器、堆疊與私有呼叫。

| 入口 | 已確認的靜態行為 |
|---|---|
| `0x838E` | 以 4-byte 步進檢查兩個位置的 halfword／byte 條件；將長度上限設為 30 bytes，組裝 2-byte 標頭與內容並交給既有分派函式。保留 80-byte stack frame 與兩路選擇順序。 |
| `0xA38E` | 依 GP+357 的 byte 判斷模式 1／2，再依既有狀態函式作條件反相或保留結果；最後只保留低 bit，不擅自把中間值都正規化為布林。 |
| `0xA3CC` | 依無號門檻 34、16 位元幅值門檻 61 及其他狀態決定是否處理；否則遞增且截斷 byte 重試計數。結果大於 29 時清零並傳遞自身回呼位址，其他情況以參數 1000 重排。 |
| `0xAB5E` | 讀取名義 RAM 位址 `0x2000BEE9` 的完整 byte。 |
| `0x10556` | 有號讀取 GP+320 的 halfword，依符號計算幅值，再截斷並零擴展至 16 位元。保留 -32768 對應 32768 的原始指令語意。 |
