# 功能狀態與記錄：離線重建

本輪新增 19 個選定函式本體，重用已存在的前段提供者；1,260 bytes、424 條指令、83 個直接轉移與 16 組程式／資料位址參照已通過 C11／C++17 原始指令比較。仍使用保留暫存器與私有呼叫的組語 port。

| 範圍／入口 | 已確認的靜態行為 |
|---|---|
| `1056E..1061C` | 五個記錄欄位判定：byte／halfword 零值、byte 3 型別 9／10 或 4、byte 4 上限 14，以及 byte 5 遮罩／允許值。讀取寬度與分支順序均保留。 |
| `106C0`／`106E0` | 依 GP+84 指標所指 byte 8 的有號值決定是否傳遞 selector 至尚未提供的 `EBAC`；共用入口以 selector 82 呼叫。 |
| `107C6` | 透過私有 A3／A4 參數執行判定；真時遞增並截斷 byte 計數，達無號門檻後清零並交給既有狀態處理，假時清零。沒有新增上下限。 |
| `10870`／`10AC6`／`10B0A` | 依不同 byte 與 bit 優先順序產生 selector 82..87；保留分支優先順序、共享處理與原始排程參數。 |
| `108D8`／`10936`／`10944`／`109C4`／`10A00` | 判定與狀態門控後修改記錄：型別、nibble 計數／查表、兩組大端序 halfword 各加 200、byte 加 25，或特定 byte 固定值；再呼叫既有輸出函式。 |
| `10A16` | 對 byte 欄位加一後執行原始 signed REM 15；依模式與 halfword 零值選擇三張尚未提供的表，分支各自保留原有固定值與清零操作。 |
| `10B60` | 依記錄 halfword ID 選擇判定函式、GP 計數 byte、無號門檻與模式；部分 ID 有兩次依序處理。 |
| `10C1E..10C36` | 設定 ROM slot 72 的 A0 名義位址、A1=0、A2=20 並尾轉移；保留後方原始 RET，不另宣稱它是已確認的獨立函式。 |

新增未提供依賴為函式 `EBAC` 與資料位址 `1A4E4`、`1A518`、`1A528`、`1A538`。尚未擷取、辨識或提供這四段查表內容，也沒有用合成表替代，因此尚不能宣稱記錄改寫已可獨立運作。

完整來源證明通過 216 組／432 個物件；接上十一個舊依賴並新增五個缺口，尚缺 126 個。45,345 個選用原址 bytes 吻合；靜態流程涵蓋 2,489 個直接轉移，一般延續位置無缺口，選用元件已無缺少本體的回呼位址參照；執行期間接目標仍未證明。時間單位、功能歸屬、私有 ABI 與硬體／OTA 尚未證明；沒有執行目標或硬體，沒有新 BIN。
