# 主初始化、暫存器設定與8-byte資料載體

[English](readme.en.md) · [C/C++](../../src/native/receive/main_runtime_family.c) · [原始證據](evidence.json) · [驗證摘要](summary.json)

新增6個完整原始函式704B／241指令，C11／C++17原址編碼一致。四個舊入口8E88／9958／9F12／9E84已接上；展開8個新依賴後，真正缺口由71變75。不是功能倒退，也沒有占位實作；[清單](next-providers.json)分別列出直接呼叫與PC-relative位址參照。

| 原始範圍（結尾不含） | 已確認靜態行為 |
| --- | --- |
| 8E88–9008 | 完整32B frame與S0/S1；保留ROM表項讀取、初始化順序、config byte7低2位分支。第一個tuple是A0=0x2000B18C／A1=0／A2=2124；ROM語意未證。 |
| 937E–93AA | 從9E84回傳的堆疊載體取半字，呼叫9334後比較，將布林值寫入GP+167。 |
| 9958–99E8 | 保留ISA DIVU、GP+108時脈word、16位截斷及原始半字RMW；low16(clock/1000000−1)寫至0x40000428，最後尾呼叫93EE。 |
| 9E5C–9E84 | 保留272B frame／RA+268，將8-byte tuple傳給ROM表項，再以A0=0x08077B00／A1=SP呼叫尚未實作9C0A。未證實際儲存寫入。 |
| 9E84–9EA6 | 將A0=SP／A1=0x08077B00／A2=8傳給word[0x4004C]，再以兩個word回傳A0/A1。 |

8614有3個位址參照，8C82有1個；兩者只作未實作的回呼候選，未被ABS假函式代替。資料候選指標19DEC／19DFC／1AB34尚無元件所有權證據。0x08077B00的內容不在此BIN中，且ROM表項語意仍未知；不推定為VIN、金鑰或特定設定，不將copy形態的參數視為已觀察記憶體讀寫。暫存器結構呈現計時器形態屬推論，實際晶片／週邊／時序未證。

主元件16808B code＋674B data，共17482B經原生連結器配置後逐byte等於官方ID2966 BIN。來源108個C/H檔、81個code單元；164項比較／328個物件通過，舊107檔與961筆產物記錄保持不變。955直接轉移中882個有實作目標、73個只有參照；另有2個僅透過位址載入的提供者，故UND共75。間接轉移298、潛在返回356；不是完整CFG或執行證據。

值得新增的候選工具：離線比較不同版本的8-byte載體與byte1/byte4正規化，保留未知欄位；在ROM／儲存契約確認前不新增硬體備份還原。下一步追查8個新提供者及三個常數指標。全程離線，未執行韌體／HOST模型／ISA模擬，未連硬體。診斷ELF入口0／PT_LOAD=0，尚不可燒錄。歷史隱私問題待清理，未commit／push。
