# v4.1.60：具名別名盤點與 18 個別名批次驗證

接續[六個別名的對照](v4160-direct-alias-batch-six.zh-TW.md)。按輸入 ET_REL 盤點其餘 66 個別名：確認有保留區段的引用、被引用符號在引用處未定義、目標有唯一強全域定義且其區段保留、目標不是另一個別名、來源物件沒有同名符號、同一物件內沒有替換目標碰撞。這組診斷輸入的結果為 66 項符合、0 項延後，僅表示可進入連結驗證。

從符合條件者依名稱排序取前 12 個，和原六個合併測試：18 個別名、21 筆輸入重定位、7 個 ET_REL 物件，剩餘 54 個別名。只刪除別名不改引用，嚴格連結如預期失敗；改成直接引用後，6,364 個配置區段的內容及位址與原診斷連結相同，覆蓋的 76,800 bytes 逐位元組等於原 BIN。一般 Python 與 `-O` 各測 C／C++ 基準與 split/leaf 候選四路，結果一致。

未修改原 BIN 或正式來源；仍含 resident 數值見證及 BIN 取樣，非獨立可刷寫映像。本提交只發布報告。本機驗證入口為 `experiments/v4160-aggregate-no-ident-next/verify.py --full`，沿用 baseline 與 llvm-objcopy 參數。下一步驗證全部 72 個具名別名同時移除，保留 resident 為獨立的尚未解決依賴。
