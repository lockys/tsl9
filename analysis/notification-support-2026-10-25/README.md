重建六個完整函式，共216B／71條指令：B664、B6A8的狀態位元判斷；CC60的紀錄欄位設定；CCC2的條件式清理；CCF6的條件式byte XOR1；FE08的結果反轉及尾呼叫。保留原始暫存器、volatile存取、分支順序與私有組合語言介面。
