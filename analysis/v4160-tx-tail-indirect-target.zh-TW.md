# V4.1.60 TX 尾跳：載入值與有效目標

既有固定視窗對照見 `analysis/tx-tail-dataflow-verification.md`。參考 BIN 在 `0x8b46` 以 `lw t1,80(a5)` 讀取位址 `0x00040050`，於 `0x8b50` 執行 bytes `02 83`；既存 TX 整合候選的對應位置分別是 `0x8b60`、`0x8b6a`，尾跳 bytes 相同。這裡 `a5=0x00040000`。

`02 83` 為 `c.jr t1`：在正常完成指令的前提下，有效目的位址為**當時 `t1 & 0xfffffffe`**，不是未處理的 word 值；例如載入 `0x1235` 時目的位址是 `0x1234`。這個跳轉不寫入 `ra`，兩側先前都從 `28(sp)` 恢復 `ra`（參考 `0x8b26`、候選 `0x8b40`）。此低位清除作用於跳轉目標，不會修改 `t1` 寄存器的值。

這僅是固定指令與 RV32C 語義的局部推論，不證明 `0x40050` 的讀取有效、內容真為函式指標、目的地可執行、兩個影像所有路徑等價、ABI 相容或完整映像重建。別名、例外及非同步干擾仍須另行處理；未執行目標或模擬器。
