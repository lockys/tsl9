# 動作底層與週期輸出：離線 C/C++ 重建

[English](readme.en.md)

九個完整函式共684B／231指令與24B相對表，已納入 [action_primitives.c](../../src/native/receive/action_primitives.c)。C11／C++17核對全部原始程式／表bytes與62個重定位。[原始證據](evidence.json) · [位址契約](provider-contracts.json)。

- **已確認：**1552A設定pending byte358，前輪155D0消費後轉入18110。15532把輸入最低位寫入設定bit8，但後續分支／尾跳參數仍保留完整輸入，未簡化成布林值。
- **已確認：**1802E合併或覆寫完整遮罩；17F80鏡像後呼叫17C4E，再重新讀取遮罩／計數欄位。1805A使用六項表／四個目標，輸出後重新讀取階段byte再REM6。[階段常數](phase-map.json)。
- **已確認：**1811A保留旗標更新、條件延遲參數與啟動／取消路徑。2／20／100／200／300／8000僅是原始數值，時間單位與排程模式未證。
- **未確認：**產品功能名稱，包括bit8是否名為免打擾。接上六個舊入口、新增17C4E／9AE4兩個依賴，仍有181個真實匯入缺口。[清單](next-providers.json)。

完整來源證明涵蓋122個C/H檔、192組比較／384物件；原121個C/H檔與1129筆產物記錄不變。未重跑舊V4.1.00行為模型測試。主元件31,468B code＋1,750B data／2,069重定位；選定33,218B在名義原址逐byte吻合。診斷ELF入口0且**沒有PT_LOAD**。靜態流程核對11,050指令、1,853直接轉移與669個呼叫返回位置，一般續行沒有缺口；原253項動作表及新增六項階段表都核對實際連結資料，但執行期目標、488個間接轉移、10個MRET與trap恢復仍未證。[摘要](summary.json)。

[新功能候選](feature-candidates.json)整理只讀輸出診斷與階段數值清單，尚不構成硬體功能成功。本輪不執行韌體、HOST模型或ISA模擬，不操作硬體、BLE／CAN／Flash或原廠網路，不產生BIN。MCU、installed ROM、完整啟動／RAM／IRQ與OTA相容性未證。
