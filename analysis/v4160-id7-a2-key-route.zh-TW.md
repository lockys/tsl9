# 任務 7：A2 訊息的 33 用來查找記錄

範圍：v4.1.60 APP 與 WCH V1.31 候選常駐程式（SHA-256 `133d37055626caa1ac0f0abd0b8ec4d8c5786a61d52e6a2ef24ae2705aa15a22`）。以下為靜態指令與有限合成 RAM 投影，不是實機記錄；假設候選映射、Xwchc、正常存取、分離的堆疊和無干擾。

- A2 呼叫 `0x4572c(33,65535,M)`。第三參數存於當前 `sp+12`；第二參數存入 s0。第一參數經 `0x4f058` 傳給 `0x20000a94`。後者取 `U8[0x200033b4]` 筆和 `U32[0x20003354]` 基址，每筆 60 bytes，依序比較偏移 +2 的 little-endian 半字；第一筆相符即返回該筆地址，不是用 33 直接索引。
- 無記錄時分類值是 0；非空命中則在條件 Xwchc 下 `0x4f066` 讀記錄 +12 的一個 byte。只有分類 4 使用 `U32[0x20002f24]` 所指表的 +0；其餘使用 `U32[0x20002f1c]` 所指表的 +4。表指標或函式字為 0 就返回 1，否則尾呼叫，a0=65535，a1=從堆疊重讀的 M；此段不再解讀訊息內容。缺失記憶體不能當零。
- 原有 128 個取回新 M 的合成案例，查到的五個半字全為 `0xffff`，33 均未命中；最後均返回 1 而未尾呼叫。沒有證據顯示實機記錄必然為空，亦未判定呼叫者如何解讀 1。
- 本機驗證：一般 Python 與 `-O` 各通過 128 個沿用初始化記憶體的案例，另各通過 512 個獨立命中／未命中與分類案例，每例分別核對表字缺失、表指標零、函式字缺失、函式字零、函式字非零五種結果。此提交只發布分析紀錄，不含候選映像或完整本機驅動。
