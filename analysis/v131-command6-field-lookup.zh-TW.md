# 命令 6：兩個欄位與第一次呼叫

接續 selector 5 偶數命令：以候選 V1.31、Xwchc 解讀及已成功的四位元組解析為前提。以下令 A、B 為 sp+8、sp+10 的兩個小端半字。

0x4df7a 取 A 交給 0x4d5a0。該函式先讀 0x20002fa0 的 byte 數量及 0x20002f98 的 word 表指標，再依序比對每筆 16-byte 記錄的 +2 半字。零值跳過，非零而等於 A 時回傳第一筆符合的記錄位址；掃完回傳 0。B 不參與查表。

- 命中且位址非零：s3 保存該位址，呼叫 0x4ea8c(識別值,7,header[1],sp+8,0x4ec8a)。此時交的是 A/B 的位址，不是 B 的值，也不是原本文指標；0x4ec8a 只是第五個參數，本段並未執行它。
- 未命中：依序在 sp+0/+2/+4 寫半字 2/A/B，呼叫 0x4ed36(識別值,header[1],sp)。

以 SHA-256 133d37055626caa1ac0f0abd0b8ec4d8c5786a61d52e6a2ef24ae2705aa15a22 為身分檢查，離線測試涵蓋空表、零鍵、重複鍵與 255 筆表末命中。普通 Python 與 -O 各 105 條 trace（84 未命中、21 命中），核對所有資料讀取位址及寫入欄位。只驗到上述下一次呼叫的入口；堆疊與資料區互不重疊，沒有觀察到真機表內容，也不能宣稱兩個被呼叫函式不改旗標。
