# V1.30 resident：0x91／5 訊息的連線欄位來源

本文延續[組包紀錄](v130-boot-message-91-sub5.zh-TW.md)。核對的是 V1.30 resident **參考候選**，映射基址 `0x40000`，SHA-256 `8fd279d4bc08bea74625e0ef3b8ca873746a84bf430c46a7565482effd96a04c`，非裝置讀回映像。

- 在 `0x5e19e`，原始位元組 `0e24` 依 WCH Xwchc 欄位解碼為 `qk.c.lhu a1, 8(s0)`；通用反組譯器將同一編碼顯示為浮點載入，不應沿用該助記符。此處讀的是當下連線紀錄 `+8` 的無號半字。
- `0x5e1a0` 呼叫 `0x6a586`；後者以 `jal x0` 尾跳 `0x52d58`，不改 `a1`。組包函式在 `0x52d62` 暫存 `a1`，配置成功路徑於 `0x52d72` 重載，並在 `0x52d84` 寫入訊息 `+4`。

驗證：重算候選 SHA-256，從原始編碼獨立解算半字載入的暫存器與偏移、核對呼叫／尾跳的目的地與連結暫存器，以及組包端的保存、重載與寫入編碼。這只建立候選的靜態資料流，不證明特定 BOOT 連線的實際編號、執行順序或實機 ROM 版本。
