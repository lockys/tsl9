# V4.1.60 `0x105c4` 呼叫邊界：有限靜態歷史摘要

## 身分與前提

歷史實驗固定的 decoded BIN 長度為 76,800 bytes，SHA-256 為 `0ee64183daaa140acac7dbb6c0f7c26d1fe625344ed158151731a9b2632fb667`。以下採用 RV32 little-endian、含 compressed 指令，並**假設**檔案 offset 0 映射到 PC `0x8000`；此映射未經驗證，雜湊也不證明來源或映射。所選指令邊界及進入狀態都是假設，不是可達性證明。另假設記憶體存取成功，且暫存器、程式碼與保存槽不受非同步修改。compressed indirect call 的連結位址是下一個 halfword；`jalr` 清除目標位元 0。

## 三條獨立位元欄位檢查的有界控制流邊

1. `0x153f6 → 0x10944`：JAL 的 link register 為 `x0`，是 tail jump。先前 `0x153ee` 將當時的 `s0` 複製至 `a0` 並還原 `s0`、`ra`、`sp`。在所選後續路徑中，`0x10944` 保存傳入指標，經 `0x1083c`，由 `0x10846` 間接呼叫具體化的 `0x105c4`；該 leaf 讀取指標 +3 的 byte，回傳其是否等於 4。這只是條件式進入路徑，不代表其上游歷史完整。
2. `0x10b7e → 0x10bc2`：BEQ 比較暫存器 `x15` 與 `x13`。在所選前驅 `0x10b60` 讀取 `a0` 所指 halfword 並令 `a4 = a0`；若其值為 540（`0x21c`），所選比較導向此邊，途中未改變 `a0` 或 `a4`。僅直接進入 `0x10bc2` 本身不能確立兩者相等。
3. `0x10bda → 0x107c6`：JAL 的 link register 為 `x1`，返回位址 `0x10bde`。此呼叫的 callback 是 `0x1056e`，**不是** `0x105c4`；在 `0x107d6` callback 接收繼承的 `a4`。有效存取下，`0x1056e` 只讀取 byte／halfword，當 +3 byte 為 9 或 10、+4 和 +6 halfword 均為 0、+8 byte 為 0 時回傳 1，否則回傳 0；其有界本體不修改記憶體、`sp`、`s0`、`s1` 或 `ra`。

## 回傳、計數與外部條件

`0x107c6` 配置 32-byte frame，保存外層 `s0`、`s1` 和 link；callback 回傳 0 時清除計數 byte。非零時先以 **modulo 256** 加一；新值小於 10 則寫回並返回，**新值大於等於 10** 才清零、呼叫 `0x820c`，還原 frame，並以保存的 `s1`（此呼叫為 2）作為 `a0` tail 至 `0x1074c`。例如原值 255 會回捲為 0，而不是觸發門檻。

`0x1074c` 的所選路徑呼叫 `0xd272`、`0xb0fc`、`0x820c`、`0x10032`、`0x12b24`、條件式 `0x9124`，再呼叫 `0x13d48`。上述首次門檻路徑的 `s0 = 2`，因此包含 `0x9124`，且與 6 不相等；只有這些外部呼叫均返回並保全活躍的 `s0`、`sp` 和保存槽，局部還原後才可返回 `0x10bde`。一般的 `s0 == 6` 分支改為還原 frame 後 tail 至 `0x9124`，還需該目標返回保存的 `ra`。外部 callee 的行為並未獨立確立。

外層 `0x10bc2` 的 16-byte frame 將進入時 `s0` 存於 `[sp+8]`、`ra` 存於 `[sp+12]`，並將入口 `a0` 保存於 `s0`。即使實際返回 `0x10bde`，要把還原後的 `a4` 認作原始輸入，仍須外層 `s0`、`sp` 和兩個槽完整；此處複製 `s0` 至 `a4` 並還原外層 frame。後續 `0x10be4` 具體化 `0x105c4`，`0x10bf0` 使用當時的 `gp+327`，`0x10bf6` 經 `0x10bbe` tail 至 `0x107c6`；在間接目標與路徑條件成立時，第二次 `0x107d6` 才以該 `a4` 呼叫 `0x105c4`。首次計數位址為當時的 `gp+326`；首次呼叫後 `gp` 仍正確是獨立假設，並非 frame 保存可推得。計數器、輸入資料、堆疊或 callee 寫入之間的 alias 不得破壞相關資料與保存槽。

另一條 `0x1083c` 零值路徑會局部還原 `s0`、`ra`、`sp`；非零路徑則呼叫 `0x820c`、`0x9124`，須兩者返回並保全活躍 `s0` 與 frame，局部還原及結果才成立。外層 `0x10966` 的指標同樣依賴還原後的 `s0`；tail 目標 `0x12a08` 與上述外部呼叫未在此界定。

## 歷史驗證與限制

本機操作者的歷史紀錄稱：對固定 BIN 的長度、雜湊與所選視窗進行離線檢查；既存反組譯 capture 的連續涵蓋、指令位址、長度與 bytes 對照 BIN，**不是反組譯語意驗證**。獨立 RV32 位元欄位解碼只交叉檢查上述三條邊的 opcode、分支條件／暫存器、JAL link 暫存器及目的地，不獨立驗證每條指令或其語意。

歷史測試記錄為一般 Python 與 `-O` 模式各 **5 項通過**；包含正確與截短／修改輸入，以及重新固定雜湊後的邊指令變異，以觸及獨立檢查。審查者回報修正後無尚存正確性問題，並確認兩種模式各 5 項通過；這是本機操作者與審查者的歷史陳述，不是本摘要重新執行的驗證。

這些視窗不枚舉所有直接進入邊；間接呼叫、計算位址、替代入口、外部 callee 及 alias 仍有未解部分。**不主張完整 caller 集合、原始 ABI／prototype、可達性、執行期保存或行為，也不主張完整 BIN 等價。** 本次摘要未安裝、執行、模擬或燒錄目標。
