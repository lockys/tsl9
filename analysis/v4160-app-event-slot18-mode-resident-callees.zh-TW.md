# v4.1.60：模式寫入前兩個候選子呼叫的保留邊界

接續[兩個 resident 候選入口](v4160-app-event-slot18-mode-resident.zh-TW.md)，核對 `0x43932` 的兩個無條件子呼叫。

- `0x20000314`：按候選複製對應，flash `0x40584..0x405a2` 提供 30 bytes。程式從 `0x200031e8` 讀取鏈首、走訪節點，回傳命中指標或零。按候選 Xwchc 解讀，這段是只讀葉函式，不寫 `s0`、`s1` 或 `sp`，也沒有巢狀呼叫；正常返回仍以有效且可終止的鏈為前提。
- `0x43728`：先保存 `s0`。若輸入索引不小於容量，或候選回呼指標為零，走 `0x43764 → 0x437b2`，不進入子呼叫，從原槽還原 `s0` 後返回。其餘路徑尚不能做同樣推論：在 `0x437ca`、`0x43842` 已找到兩個條件式間接呼叫，且還有直接子呼叫。

離線 Python `-O` 通過候選 SHA-256、30-byte 查表指令窗、鏈首位址、兩個早退分支目標、`s0` 儲存與還原，以及兩個間接呼叫指令。這不是對完整 `0x43728` 的驗收；下一步先判斷模式 1 呼叫的輸入能否證明走早退，否則保留回呼副作用為未知。沒有執行固件或連接設備。
