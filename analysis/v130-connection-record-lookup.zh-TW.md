# V1.30 resident：連線紀錄查找

以基址 `0x40000` 核對 V1.30 resident 參考映像，SHA-256 `8fd279d4bc08bea74625e0ef3b8ca873746a84bf430c46a7565482effd96a04c`。本筆延續[移除訊息欄位來源](v130-boot-message-91-sub5-upstream.zh-TW.md)。

`0x576ec` 從 `0x20003304` 讀取串列頭指標。對每筆非空紀錄，`0x576fa` 的原始位元組 `9a27` 依 Xwchc 解碼為 `qk.c.lhu a4, 8(a5)`；`0x576fc` 把該無號半字與完整的 `a0` 比較。相等即回傳目前紀錄；不等則讀紀錄 `+0` 的下一筆指標。遇空指標即回傳零。這與先前組包路徑從同一紀錄偏移 `+8` 取值的結果一致：`+8` 既用於查找，也用於填入移除訊息的連線欄位。

驗證重算了映像 SHA-256，核對頭指標位址、Xwchc 半字載入欄位、比較指令與跳轉，以及鏈結讀取和返回編碼。這是參考映像的靜態查找行為；尚未驗證紀錄建立時如何指派該值，也不能推定某次 BOOT 的實際編號或裝置使用的 resident 版本。
