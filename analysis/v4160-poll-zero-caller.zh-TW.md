# 同一個零，在兩層返回值中意義不同

`0x16994` 的第三次 `0x16896` 傳輸以 0 作輸入。返回後清理指令不動 a0，所以送出等待逾時、接收等待逾時、成功收到低 byte 0，三者都能把同一個 0 帶到 `0x16e7c`。三者先前對外設的讀寫不一定相同。

`0x16e0c` 的輪詢先取時間。以 unsigned 32 位差值判斷，差值 >2 直接返回 **1**，不再讀本輪狀態；否則讀取位址參數 14 的狀態 byte。只有 `0x80..0x9f`（遮罩 `0xe0` 後為 `0x80`）使外層返回 **0**。其他 224 種 byte，包括零，都跳回 `0x16e58` 重取時鐘，沿用原始基準，不是直接失敗或成功。

上一層 `0x16e88` 把這個 **外層狀態碼**存進 s1。非零分支至 `0x16ef4`，跳過後續設定呼叫並返回保存的值；為零則落入 `0x16e9a` 的設定路徑。在各被呼叫者正常返回並保存 s1 的條件下，返回的是原先保存的輪詢結果。這不表示設定呼叫一定成功。
