# 查找表讀取視窗（實驗）

[English](readme.en.md)

本頁保留獨立實驗與當時 88.32% 基準；後續已完成[正式來源與原位址整合](../grid-integration-2026-10-25/README.md)，目前位元組覆蓋率為 88.89%，實機／OTA 相容性仍未證明。

從原廠 BIN 新擷取 86 條指令，核對已重建 CODE 的 21,938 條指令／64,544 bytes。前兩條讀取路徑的保守視窗聯集為 **432 bytes**：一個真實唯讀配置，兩個位於偏移 0／320 的零配置 DATA 標籤。

C11 與 C++17 編譯物件相同；兩套 ELF 讀取器一致。實驗性 ET_REL 連結保留既有 CODE／DATA、四個舊 DATA 標籤與 4,861 個重定位，未解參照由 24 降至 22。

第三條路徑的 `AND 7` 寫入 A3，實際查表索引使用 A4；不能據此宣稱索引為 0–7。僅由 byte 型別推算的視窗會超過映像結尾，但這不等於已證實執行時越界，因此仍未提供第三個資料相依。

尚未納入正式 `src/`、完整來源證明或原位址配置；正式覆蓋率仍為 **88.32%（67,833／76,800 bytes）**。沒有產生 BIN、執行目標／HOST 模型／ISA，或連線硬體／後端。間接入口、非同步影響、原始宣告大小、實體功能與 OTA 相容性尚未證明。
