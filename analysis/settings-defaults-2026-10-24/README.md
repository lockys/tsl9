# 設定預設值與持久化包裝

[English](readme.en.md) · [C/C++](../../src/native/startup/settings_defaults.c) · [原始指令](evidence.json) · [驗證摘要](summary.json) · [寫入契約](persistence-contract.json)

新增十二個完整函式878B／297指令、31個私有區塊、12個控制重定位與一組資料位址重定位。六個原先缺漏的fallback已具真實實作，六個寫入包裝也已分開重建。未解析提供者75→70：69個有直接控制參照，另1個僅為未提供內容的資料位址。

主設定的原碼會以四byte來源位址，透過ROM copy複製到GP+84載入之runtime指標加12。程式保留這個流程，來源以真實未定義資料符號tsl9_settings_default_data_1a69c表示；沒有輸出內容、獨立內容雜湊、猜值或替代資料。來源位址與資料內容是不同的證據，診斷ELF只保留參照地址，不能據此宣稱資料已重建。

六者保留272B frame與RA+268，經ROM slot0x4004C複製，再呼叫既有9C0A。9C0A呼叫18EF2；其原始迴圈每次讀／寫4B，offset到256結束。因此短記錄後綴的內容並未由包裝函式確認。未執行硬體，不宣稱實際寫入失敗或資料外洩，也沒有擅自補零、補FF或改變原碼。

目前116個C/H檔、89個code單元，含獨立指標資料共180項比較／360個物件，舊115個來源與1057筆產物記錄不變。主元件21866B code＋714B data，共22580B在原生原址配置後逐byte等於官方ID2966 BIN；這個範圍不包含未提供的四byte資料。

流程覆蓋7584指令、1212直接轉移（1143已重建／69僅參照）、7013個一般下一位置無缺口、467個可能呼叫返回位置；393個暫存器間接轉移、10個MRET與1個EBREAK仍非完整CFG或實機證明。診斷ELF入口0、PT_LOAD=0，不可燒錄。

下一步追查其餘主執行層入口與ROM／BOOT／APP／IRQ相容性。值得新增的功能是設定更新完整性與保留頁面未知bytes，等硬體與映射證明後再評估整頁讀取、覆蓋已知記錄與寫後讀回；目前僅提案，現有重建維持原行為。未執行目標、HOST模型或ISA模擬，未操作硬體／網路；歷史隱私問題未清理，未commit／push。
