# 原始輸入解析器與函式指標資料

[English](readme.en.md) · [C/C++](../../src/native/receive/incoming_protocol.c) · [原始證據](evidence.json) · [驗證摘要](summary.json)

新增85C8／888C／8B90三個完整函式776B／262指令，以及四段40B的真正C唯讀資料。C11／C++17原址編碼均相符；19DE0及19DFC中的三個原始函式指標已指向重建的程式。新增13E0E／14056兩個下游缺口，UND由72變74，仍保持未實作。

| 原始範圍（結尾不含） | 已確認靜態行為 |
| --- | --- |
| 85C8–8614 | 比較GP+150/154半字；保留低16位參數條件與原始ROM事件tuple，未推定時間單位。 |
| 888C–8A56 | 保留標頭bit0x20、type2、0x2902與handle比對；有效解析路徑使用64B frame，含第一個RET後的全部狀態分支。 |
| 8B90–8C82 | 處理原始事件值2/3/4及子型5/6，保留GP欄位、0xFFFE清除值與後續13E0E呼叫。 |

解析器使用55/7F同步、命令byte、兩byte大端長度、最多1040B本文及低8位加總檢查；檢查通過才呼叫14056。無效資料、超長、校驗不符及原始差值門檻299的重置路徑完整保留，時間單位未證。這是編譯碼／靜態證據，未執行封包、韌體或模擬器，未改任何驗證條件。

| C資料前綴 | bytes | 原始內容範圍 |
| --- | --- | --- |
| 19DE0 | 12 | 8B90、NULL、85C8三個指標槽 |
| 19DFC | 12 | NULL、888C、NULL三個指標槽 |
| 19DEC | 13 | 原始固定載體前綴 |
| 1AB34 | 3 | 原始byte查表前綴 |

40B來自實際C物件；三個非NULL指標使用真正R_RISCV_32參照，未填補19DF9–19DFC的未知間隙。四個已知候選位址現在都有資料所有者，但ROM讀取的完整結構長度、型別／ABI及實際註冊行為仍未證。199E2／19B16目前顯示為更底層啟動設定，未建立先前假設的直接註冊關聯；此輪連結以原廠資料指標為證。

主元件18656B code＋714B data，共19370B原生原位址配置後逐byte等於官方ID2966 BIN。來源110個C/H檔、83個code單元；168項來源比較／336個物件通過，舊109檔與985筆產物記錄保持不變。1055直接轉移中981有實作、74只具參照；339間接轉移及395潛在返回仍非完整CFG／執行證明。

候選新增工具：離線框架長度、加總與錯誤重置診斷，目前僅提案。下一步追查14056命令分派與13E0E狀態處理，再收斂ROM／記憶體契約。全程離線、未操作硬體。入口0／PT_LOAD=0診斷ELF仍不可燒錄；歷史隱私問題未清理，未commit／push。
