# 定時記錄與旗標：離線重建

八個完整函式已重建為 C，並分別以 C11／C++17 編譯。418 bytes、138 條指令、20 個直接轉移與四組回呼位址均通過原始指令比較；組語 port 保留了原機的暫存器、堆疊與呼叫行為。

| 入口 | 已確認的靜態行為 |
|---|---|
| `0xBD46`／`0xBD50` | 分別回傳 `0x2000BF11`／`0x2000BF10` 指標。 |
| `0xBD64` | 讀取 `0x2000BF13` 的 byte。 |
| `0xEDF2` | 取記錄 9，以完整 byte XOR 1 切換旗標，將其低 bit 放入記錄 byte 3 的 bit 2，交給既有輸出函式。 |
| `0xEE30` | 先執行上述切換，再比較 halfword 計數與上限；依指標表取得 halfword 參數並安排自身回呼，或清除上限與旗標。兩路最後都遞增 halfword 計數。 |
| `0xEE9A` | 依旗標決定是否清除狀態、將 `0xEE30` 位址傳入既有函式、清零計數 word 並執行切換；回傳 0 或 1。 |
| `0xEEE0` | 輸入為零時切換並排程，以模式選擇 11／50 參數；byte 計數減一並回繞，再依條件以 100／200 或先前參數排程自身。非零輸入清除另一旗標。 |
| `0xEF6C` | 回傳切換旗標的完整 byte。 |
