# 角色配置：相鄰位元組是在配置返回後才取樣

沿用 8 個 APP／V1.31 參考程式執行狀態，在 `0x4daf6` 為每個非零 N 各開一個獨立分支。每支只補 `0x20003350=N`；不重建堆積、不預設返回指標、不填相鄰的 `0x20003351`。各支使用自己的寫入覆層，不累積 255 次配置。

| N | 請求 bytes | 8 個狀態的返回值 |
|---|---:|---|
| 1..3 | 16/32/48 | 原先建立計時器時為 `0x200043cc`；拒絕計時器的對照為 `0x200043b4` |
| 4..255 | 64..4080（每次加 16） | 全為 `0x200049e0` |

參考配置器在 `0x20000078` 比較對齊大小與 52，大小分流與兩組結果一致。2,040 次返回都在 APP 配置池範圍內；返回指標之前的半字標記皆為 `0x4c04`。呼叫者先在 `0x4db1c` 把指標寫到 `0x20003310`，`0x4db22` 重讀 N，`0x4db2a` 才讀相鄰 byte；此時因該值無證據而停止。8 個獨立對照直接把呼叫者返回值換成零：仍先寫指標欄，然後跳 `0x4db3e`，兩個 byte 都不讀。這不代表原堆積曾配置失敗。

本機 `analysis/check_v4160_role_rf_to_heap.py` 與 `analysis/v131_count_alloc_neighbor.py` 在一般 Python 與 `-O` 各通過 2,040 個非零計數案例及 8 個零返回對照。V1.31、Xwchc 與合成外設是前提；兩個計數都不是設備讀值。
