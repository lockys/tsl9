# TX register/frame ABI: formal component evidence

[繁體中文](readme.zh-TW.md)

The public producer is `experiments/tsl9-v4160-tx-register-abi/verify.py`, wrapping this directory's verify_native.py. It freshly compiles C11/C++17 and applies explicit narrow entry and compiled-word scheduling layers. Actual extent is280B. It produces no BIN or full-image replacement and never executes RV32, hardware or network operations.

```sh
sh experiments/tsl9-v4160-tx-register-abi/verify.sh --project-root . --tool-dir /path/to/audited/llvm/bin --language both
python -B analysis/v4160-tx-register-abi-2026-10-22/implementation/check.py --project-root .
python -B experiments/tsl9-v4160-tx-register-abi/verify.py --project-root . --replay /path/to/ordered/c/verification.json
```

Research uses apk-analysis/tsl9- instead of published analysis/. Default output is a fresh UUID build; explicit --build-root must be new and inside this model's build/. --firmware supplies pinned original validation evidence only, never generated bytes. Replay is read-only and rejects build-only options.

pre/{c,cpp} retains three fresh source objects: raw assembly entry without preprocessing/includes, typed body and typed returning leaf. Both typed LLVM IR outputs are kept. Actual -MD closure is three project inputs for body, one for leaf and one Clang resource include/stdint.h. The assembly's direct-source dependency is audited separately. Nine native commands bind exact compiler/profile/source recipes, logs and expected exits.

ordered/{c,cpp} has seven native/Python commands: supported-feature help, explicit frame pass, ld-r composite, strict missing-RAM rejection, numeric witness, actual far-leaf branch-overflow rejection and complete explicit-ISA disassembly. The actual ET_REL has one AX280 allocation, truthful FUNC offsets0/8/278 and sizes8/270/2, exactly three standard relocations and sole real SRAM UND. Its payload must be the exact three provider payloads, without padding/fallback/public-ABS stand-ins.

The standard .reloc gives the linker ownership of branch displacement/overflow. Actual unsigned guard8A5A→8B6C precedes frame access and the rejected path preserves A0/RA/SP. Historical ordinary-C290B and assembler-expanded284B alternatives remain rejected local evidence.

The explicit pass reorders five existing SWSP words in body+2..+12 and five existing LWSP words in+208..+270. It restores source save order and fresh RA/S1/S2/S3 before descriptor SH, S0 after SH but before ROM-tail pointer read. All other word order and metadata stay exact. Storage overlaps, wrong function roles, unexpected window symbols/relocations/interior targets/callreturns and unexpected instruction inventories reject. The pass reads no original BIN, emits no new opcode, and does not assert alias/fault equivalence with unscheduled compiler output.

Independent source-review covers original frontiers, the saved-RA alias witness, source extraction and pre-motion entry. ABI-review covers real objects/IR/linked geometry, three linked byte controls, fourteen malformed-object guards and nine instruction controls for complementary loop CFG/live counter/payload/backedge/checksum. Formal replay reruns the pinned entry/frame/loop checkers against actual artifacts.

Guard, both gate RAs8A90/8AB6, save/fresh-restore frontiers and loop correspondence have improved. Public entry remains truthfully FUNC8; original whole-FUNC280 metadata is unadmitted. Whole original ABI/private or computed targets/pointwise interrupt-fault behavior/full-image integration/physical compatibility remain unproved. Numeric SRAM2000B18C is only an address witness.

results.json selects two formal receipts; receipts/ contains byte-identical JSON metadata only. Default check.py reads sealed source/metadata, not missing archives. --require-local-builds replays original local builds; --receipt accepts a fresh checkout's actual receipt. Generated objects/ELF/IR/logs stay in local excluded build/. probe_adapter.py/probe_ordered.py are pinned formal substages; diagnose.py/inspect_temp.py are historical-only and not called by the formal producer.
