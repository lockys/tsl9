# 設定與狀態輸入

[English](readme.en.md) · [C/C++ 來源](../../src/native/receive/settings_state_inputs.c) · [逐指令合約](provider-contracts.json) · [統計](summary.json)

重建14個完整函式，共1,112B／353條指令、97個私有區域。內容包含設定 byte／halfword 比對、bit 欄位更新、變更通知、checksum 呼叫、單次旗標、排程回呼及一個 ROM 間接尾呼叫。

B1B6 消耗 GP+198 待處理旗標，修改紀錄、呼叫 ED00 後再轉交12A08；B220 保留模3循環與高位旗標。B254／B29A 的三處回呼位址均接到實際重建程式；排程選值0／1／5／10乘以60000，其時間單位仍未知。B242 從0x40048載入函式指標，以 GP+196、0、3為參數尾跳；相符的是 SDK 預設表格，並非原機 ROM 函式身分。

234組比較／468個物件通過，54,878B原始位址相符，覆蓋率71.46%。補齊12個入口並暴露8個新函式缺口，仍缺98個提供者；沒有用stub代替。其他不明資料內容維持未提供。

已確認原始位元組、欄位寬度、比較／寫入與呼叫順序。推論為設定與狀態處理；實車功能名稱、時間單位、私有ABI、實體ROM/RAM、中斷與OTA相容性仍未確認。沒有目標／硬體執行或新BIN；百分比不是功能完成率或可刷入比例。候選新功能為唯讀設定差異與排程追蹤，尚未實作成App或車輛功能。
