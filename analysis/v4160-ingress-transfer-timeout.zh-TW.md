# v4.1.60 接收傳輸的逾時邊界

原始 BIN SHA-256：`0ee64183daaa140acac7dbb6c0f7c26d1fe625344ed158151731a9b2632fb667`。以下是離線靜態解讀，不是實機結果。

`0x16896` 先從 `0x40013008` 讀取 halfword，等待 bit 1；最多取樣 255 次。成功後將輸入低 16 位寫到 `0x4001300c`，再等待狀態 bit 0，亦最多取樣 255 次。第二階段成功時讀 `0x4001300c` 並返回低 8 位；任一階段逾時則返回 0。因此返回值 0 不能區分成功收到零與逾時；第一階段逾時時沒有該資料寫入，而第二階段逾時前已有寫入。

本機 `analysis/check_v4160_transfer_timeout.py` 固定原始指令位元組，對每階段首次 ready 的 0–255 合成位置做 65,536 個手寫投影，正常及 Python `-O` 均通過。這不是逐指令模擬，也未證明時序、外設讀寫是否成功或任何真實輸入到達。與先前接收 13 筆資料的地址模型相比，不能據此推定每筆傳輸成功。
