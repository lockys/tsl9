# 主初始化與設定載入

[English](readme.en.md) · [C/C++](../../src/native/startup/main_initializers.c) · [原始指令](evidence.json) · [驗證摘要](summary.json) · [位址運算證據](storage-regions.json)

新增兩個完整原始函式522B／155指令、36個私有區塊與23個控制重定位，保留第一個RET後仍被分支使用的路徑。接上12D92／131C2兩個舊入口，同時展開六個設定預設值提供者與18AB0周邊初始化依賴，真實未解析提供者由71變76，沒有用stub補齊。

12D92保留48B frame，經ROM slot0x40048清除2000C038的384B與2000C1B8的228B；兩段連續到2000C29C。接著設定原始GPIO型描述子及32B stack描述子，保留120000000／144000000／96000000比較與對應10／12／8半字值；將0x40006400與描述子交給18AB0，再保留原始暫存器bit1設定。18AB0尚未實作，不宣稱已完成原機CAN或其他周邊初始化。

131C2經ROM slot0x4004C傳遞六組載入參數；第一組檢查偏移12..15的四個byte是否在32..126，其他組檢查末byte為0x5A，不符就呼叫原始fallback。這些是程式運算元，沒有讀取或保存裝置內容：

| 來源運算元 | RAM目的運算元 | 長度 |
| --- | --- | --- |
| 0x08077A00 | 0x2000C29C | 112B |
| 0x08077900 | 0x2000C494 | 256B |
| 0x08077800 | 0x2000C30C | 256B |
| 0x08077700 | 0x2000C594 | 256B |
| 0x08077600 | 0x2000C694 | 256B |
| 0x08077500 | 0x2000C40C | 133B |

載入合計1269B，RAM運算元跨度2000C29C..2000C794之間仍有2000C491..2000C494共3B未涵蓋，未補值。來源位址不在目前APP分析VMA8000..1AC00範圍內；不能由此檔確認實際設定、實體別名、MCU容量或BOOT／APP配置。

目前114個C/H檔、87個code單元，含獨立指標資料共176項比較／352個物件。舊113個來源與1033筆產物記錄不變。主元件20746B code＋714B data，共21460B經原生原址配置逐byte等於官方ID2966 BIN；仍有76個真實缺漏。

流程覆蓋7188指令、1183直接轉移（1107已重建／76僅參照）、6636個一般下一位置無缺口、448個可能呼叫返回位置；373個暫存器間接轉移、10個MRET與1個EBREAK尚非完整CFG或實機證明。診斷ELF入口0、PT_LOAD=0，不可燒錄。

下一步確認18AB0及六個fallback，公開預設值前先做隱私檢查。值得新增的工具是離線啟動／持久區域檢視，標明清除／載入範圍、有效性條件、未涵蓋洞與未知實體映射；目前僅提案，不改檢查或填入未知資料。未執行目標、HOST模型或ISA模擬，未操作硬體／網路；歷史隱私問題未清理，未commit／push。
