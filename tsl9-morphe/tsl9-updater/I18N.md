# TSL9 Updater i18n

0.4.0-test 使用標準 Android resources：values（英文預設）、values-b+zh+Hans（簡體）、values-b+zh+Hant（繁體），共 152 組完整三語字串。localeConfig 宣告 en、zh-Hans、zh-Hant。App 名稱、可存取描述、操作文字、錯誤、確認與 OTA 狀態均使用資源。

## 語言選擇與生命週期
App 首頁可選「跟隨系統」、简体中文、繁體中文、English。Android 13+ 使用 LocaleManager，與系統 App 語言同步；Android 6–12 由私有偏好及 Configuration context 實作。跟隨系統保留完整語言備援順序；中文先採明確 Hans/Hant，未指定 script 時才依地區推導。

語言選擇只在掃描、連線、連線中、記錄、待停止與 OTA 全部停止時開放。外部系統語言變更由 locale|layoutDirection configChanges 接收，作業進行時保留 Activity 與 BLE，完全閒置後才重建 UI。以已顯示的 locale signature 區分一般旋轉／尺寸／鍵盤變更，保留既有旋轉行為。

## 訊息與資料
UiMessage 僅保存穩定代碼和參數，UiException 承載驗證錯誤。UiStrings 在 Android UI 邊界解析巢狀訊息並檢查參數數量。Protocol、FirmwareImage、OtaSession、HardwareCapture 保持純 JVM；翻譯不改變 OTA 位元組、時序或重試策略。

硬體送來的文字、檔名、技術 debug log 與 JSON 欄位保留原文。App 不將它們送去翻譯服務。沒有 INTERNET permission。
